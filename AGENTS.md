# retroportingtoolkit.com

Live published site, not a template. Preserve real `data/` content and brand/domain/byline unless asked to change them.

- Publishing: read `docs/AUTHORING.md`. Content lives in `data/<kind>/<nn>_<slug>/index.md`; docs nest by section. `draft: true` removes listings/feeds/sitemap but keeps the direct URL. Folder names define identity/URL.
- **Pushing main deploys production through Cloudflare Workers Builds** (the `retroportingtoolkit` Worker, `wrangler.jsonc`; check the `Workers Builds: retroportingtoolkit` check run on the commit). For code/config/content changes, run `npm run typecheck`, `npm run build`, and `npm run test` first; prose-only developer docs need reference/structure checks. Publish only ready material; use drafts instead of holding dirty/unpushed work. Other deployments require owner intent; do not add automatic jobs/hooks/CI.
- If a `main` commit has no `Workers Builds: retroportingtoolkit` check after 5 minutes, the build did not trigger; do not push more commits to retrigger it, tell the owner. Nothing from the owner's Mac reaches cloud sessions: not their global instructions, logins, Keychain, or `~/dev/stack` (retired).
- Brand strings belong in `src/lib/site.ts`. Preserve ordered CSS imports in `src/main.tsx` for `src/styles/` partials.
- `data/` is validated by `npm run check:content` (the asset and heading-id checks, ~30s, no React app). `/admin` and `api/submissions.ts` commit to main **without running any checks**, so a content rule enforced only by a test is a rule the editor can publish straight past: on 2026-10-03 a creator's page lost an image it still linked, main went red, and the bot — which does run the checks — stopped publishing for everyone. A new content rule goes in `scripts/cms-validate.mjs` as well as its test.
- `src/lib/content.ts` prerenders `data/` at build time; no runtime content fetching. `/admin` (`src/pages/Admin.tsx`) and `api/cms.ts` commit to main. Keep API routes/fields/kinds aligned with local `scripts/cms-dev.mjs`; update `public/agent.md` when authoring requirements change.
- `public/_headers`: hashed `/assets/` are immutable for one year; stable-URL public media uses stale-while-revalidate, never immutable. Redirects and rewrites live in `public/_redirects`; `worker/index.ts` routes `/api/*`.

If active, wait or avoid its files. Keep commits small and the tree clean; check git history before redoing blocked work.
