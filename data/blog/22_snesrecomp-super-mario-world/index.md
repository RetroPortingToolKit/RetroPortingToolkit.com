Super Mario World was the first game used to turn SNESRecomp from a CPU translator into a working console framework. The SNES CPU can change how instructions behave based on live state, so the game's own deterministic attract-mode demo became a valuable correctness check.

The result was more than a single port. It established the runtime and comparison workflow that later SNES games could challenge and improve.
