The first SegaGenesisRecomp demo translated enough of Sonic the Hedgehog to reach Green Hill Zone as native code. It was still a technical proof rather than a finished port, but it established the basic CPU translation, runtime, and dual-execution comparison loop for the platform.

That first-day result became the seed for later Genesis games. Its importance to the Toolkit is historical: this is where the platform framework began, not where it ended.
