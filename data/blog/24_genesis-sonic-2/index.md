Sonic the Hedgehog 2 was SegaGenesisRecomp's second public game and its first serious test of generalization. Code that appeared reusable after Sonic 1 still contained assumptions about that specific binary, memory layout, and runtime behavior.

Correcting those assumptions is the real value of a second title. It pushes the framework toward describing the console rather than accidentally describing only its first showcase.
