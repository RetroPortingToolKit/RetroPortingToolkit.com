MegaManX-X is a community project by Team Resurgent, described as a "Port of MegaManX to Original Xbox Using RXDK / XDK". It takes the [Mega Man X](/software/mega-man-x) SNES recompilation, a fully playable native build produced by snesrecomp, and ports it to original Xbox hardware.

## What works today

The project is in development with no releases yet. It is a notable example of what static recompilation makes possible: because the game exists as portable native code rather than an emulated ROM, it can be retargeted at console homebrew toolchains.

No game data is distributed; the port builds on the Mega Man X recomp, which requires your own legally dumped ROM.
