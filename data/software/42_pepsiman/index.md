Pepsiman (1999) never released in the West, which makes it a fitting subject for a community recompilation with an unusual target: the browser. The project uses [PSXRecomp](/hardware/playstation) to produce WebAssembly, so the game runs natively in a browser tab rather than through an emulator.

## What works today

Per Notebookcheck's coverage (2026-07-28), the game runs at 60 FPS with widescreen, browser-based saves, offline play as a PWA, and leaderboards. It works best on Chromium browsers, with known issues elsewhere.

Retro Porting Toolkit distributes no game data for any project listed here; see the coverage for how this browser release is delivered.
