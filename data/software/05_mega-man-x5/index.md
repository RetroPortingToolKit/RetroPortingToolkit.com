Mega Man X5 is the middle entry in [PSXRecomp](/hardware/playstation)'s run of PlayStation X games, sitting between [Mega Man X4](/software/mega-man-x4) and [Mega Man X6](/software/mega-man-x6). The current release is v0.0.2-alpha (2026-08-01), so this is an early project.

## What works today

The game runs through the recompiled runtime, with FMV decoding working and an auto-skip option for those who have seen the cutscenes enough times.

## Enhancements

16:9 widescreen and frame interpolation ship as mods, both off by default.

A community randomizer fork is underway, building on this recompilation as its base.

No game data is distributed; the project builds from your own legally dumped disc image.
