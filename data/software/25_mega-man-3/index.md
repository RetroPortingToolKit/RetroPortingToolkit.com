Mega Man 3 is one of the ten commercial titles supported by [NESRecomp](/hardware/nes), maintained by the core team. It is an MMC3 cartridge, one of the four mapper families the framework handles (0, 1, 4, and 66), which its README puts at roughly 78 percent of the licensed NES library.

## What works today

The game runs as statically recompiled native code through the shared NESRecomp runner, with save-state slots available. Windows x64 is the primary and most mature platform; macOS support is experimental and newly added.

No game data is distributed; the project builds from your own legally dumped ROM.
