TwistedMetal4 Recompiled is an independent community project built on [PSXRecomp](/hardware/playstation), covered by the Japanese-language site retro-gamer.jp (2026-08-15). The pipeline is the toolkit's standard one: MIPS R3000A machine code to C, compiled to native x86-64.

## What works today

Per the coverage, the project targets PC, Mac, and Linux, and preserves the original 4-player multitap multiplayer.

## Known limitations

Rollback netcode is planned but disabled in the current release. The project's repository URL has not yet been confirmed by this site, so we link the press coverage instead.

Retro Porting Toolkit distributes no game data for any project listed here; the recompilation builds from a legally dumped disc image.
