Gumshoe is one of the ten commercial titles supported by [NESRecomp](/hardware/nes), maintained by the core team. It is a GxROM cartridge, rounding out the framework's four supported mapper families, and a light-gun game.

## What works today

The game runs as statically recompiled native code through the shared NESRecomp runner, playable with the framework's mouse-as-Zapper substitution. Save-state slots are available. Windows x64 is the primary platform; macOS support is experimental.

No game data is distributed; the project builds from your own legally dumped ROM.
