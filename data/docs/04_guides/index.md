These are the pages you open with a terminal already in front of you. Each one gets you from a stated starting point to a stated finishing point, with numbered steps, commands copied from the repositories rather than reconstructed, a checkpoint after each stage saying what you should now see, and a troubleshooting section at the end. Where a step needs a game file, the guide says so plainly and does not tell you where to find one. If you do not yet know what any of this is for, read [Start here](/docs/start) first.

- [Build a toolchain](/docs/guides/build-a-toolchain). Clone to built binary, with the prerequisites matrix and the failures that actually happen.
- [Port a game](/docs/guides/port-a-game). The flagship guide: a game file you supply becomes a running native port.
- [Write a mod](/docs/guides/write-a-mod). Package layout, the manifest, toggling and collisions, with a complete real example.
- [Translate a game](/docs/guides/translate-a-game). Hot-reloaded TOML tables, and the loop a translator actually works in.
- [Add widescreen](/docs/guides/add-widescreen). What widening really requires for 2D and for 3D, and what breaks in each.
- [Debug a divergence](/docs/guides/debug-a-divergence). Co-simulation reported a difference. Organised by symptom, from there to the cause.
- [Set up co-simulation](/docs/guides/set-up-co-simulation). Standing up an oracle and a comparison harness for one project, concretely.
- [Release a port](/docs/guides/release-a-port). Packaging, release notes, and what a release must and must not contain.
