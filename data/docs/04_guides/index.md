These guides are for people who want to work on a port.

If you only want to play a finished port, start with that port's release page instead. If you are new to static recompilation, read [Start here](/docs/start) first.

Each guide is meant to answer one practical question.

- [Build a toolchain](/docs/guides/build-a-toolchain). Build the framework before trying a game.
- [Port a game](/docs/guides/port-a-game). Start a native port from a legally supplied game file.
- [Write a mod](/docs/guides/write-a-mod). Package an optional change without rewriting the player's game file.
- [Translate a game](/docs/guides/translate-a-game). Replace text and verify it in-game.
- [Add widescreen](/docs/guides/add-widescreen). Expand the visible area while keeping the faithful path intact.
- [Debug a divergence](/docs/guides/debug-a-divergence). Find the first point where native and reference behavior disagree.
- [Set up co-simulation](/docs/guides/set-up-co-simulation). Compare a recomp build against an oracle.
- [Release a port](/docs/guides/release-a-port). Package a release without shipping files that do not belong there.

When a guide needs a game file or BIOS, use legally obtained files. This site does not provide them.
