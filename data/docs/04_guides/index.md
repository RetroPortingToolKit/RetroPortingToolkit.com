Open these with a terminal in front of you. Each guide starts at a stated point and ends at a stated point. Each has numbered steps, commands copied from the repositories, a checkpoint after each stage saying what you should see, and a troubleshooting section at the end. Where a step needs a game file, the guide says so. No guide tells you where to get one. If you do not know yet what any of this is for, read [Start here](/docs/start) first.

- [Build a toolchain](/docs/guides/build-a-toolchain). Clone to built binary, for every framework here, with the failures that really happen.
- [Port a game](/docs/guides/port-a-game). A game file you supply becomes a native program.
- [Write a mod](/docs/guides/write-a-mod). Package layout, the manifest, toggles and collisions, with a full real example.
- [Translate a game](/docs/guides/translate-a-game). TOML tables you edit and reload into the running game.
- [Add widescreen](/docs/guides/add-widescreen). What widening needs in 2D and in 3D, and what breaks in each.
- [Debug a divergence](/docs/guides/debug-a-divergence). A comparison found a difference. Get from there to the cause, by symptom.
- [Set up co-simulation](/docs/guides/set-up-co-simulation). Stand up an oracle and a comparison harness for one project.
- [Release a port](/docs/guides/release-a-port). Packaging, release notes, and what a release must never contain.
