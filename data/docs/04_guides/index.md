These are developer guides. They assume you want to build, modify, test, or release a port.

Each guide starts with what you need, then walks through the work in plain steps. Where a step needs a game file or BIOS, the guide says so. Use legally obtained files. This site does not provide them or tell you how to get them.

If you only want to play a finished port, start with that port's release page instead. If you do not know yet what any of this is for, read [Start here](/docs/start) first.

- [Build a toolchain](/docs/guides/build-a-toolchain). Build the framework before trying a game.
- [Port a game](/docs/guides/port-a-game). Turn one legally supplied game file into a native port.
- [Write a mod](/docs/guides/write-a-mod). Package an optional change without rewriting the player's game file.
- [Translate a game](/docs/guides/translate-a-game). Replace text through tables and verify it on screen.
- [Add widescreen](/docs/guides/add-widescreen). Widen a port while protecting the faithful 4:3 path.
- [Debug a divergence](/docs/guides/debug-a-divergence). A comparison found a difference. Get from there to the cause, by symptom.
- [Set up co-simulation](/docs/guides/set-up-co-simulation). Stand up an oracle and a comparison harness for one project.
- [Release a port](/docs/guides/release-a-port). Packaging, release notes, and what a release must never contain.
