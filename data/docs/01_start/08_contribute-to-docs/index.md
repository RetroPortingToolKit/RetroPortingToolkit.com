You can fix instructions, explain a missing step, or add a guide. Contributions are saved in GitHub, with a history of each page's changes.

## Sign in and get access

1. Open the [editor](/admin) and choose **Sign in with Discord**. Use an account in the community Discord server. GitHub sign-in is also available.
2. Open **Contributions** to check your linked account. If you cannot edit docs yet, ask an admin in Discord for docs access. Include your Discord username and the page or topic you want to work on.
3. After access is granted, choose **Refresh access** or reload the editor.

Founder and Community Advocate roles already grant docs access. The RPTK contributor role recognizes project contributors; it does not grant docs editing by itself. A docs grant lets you edit shared docs and create pages inside existing sections.

You do not need a GitHub account to contribute through Discord. Choose **Link GitHub** in Contributions if you need to prove GitHub organization membership or ownership of a game project.

## Edit a page

Open the page and choose **Edit this page**, or select it in the editor. Make a focused change, check the preview, and add a short edit summary explaining what changed. Choose **Save** when it is ready to be public. Publication usually takes a couple of minutes.

Use short sentences and link to sources for technical claims. Explain what you verified. Keep screenshots next to the steps they explain, and give them useful captions. Do not include private information, credentials, or game data.

If someone else saves first, the editor rejects your older version. Keep a copy of your changes, reload the page, and apply them to the current version before saving again.

## Create a page

In the editor's **Docs** list, choose an existing section, enter a clear title, and choose **Add**. The page starts as an unlisted draft. Write a short summary and the page content, then check the preview. Turn off **Draft** and save when it is ready to publish. You can leave Draft on to ask someone to review the unlisted link first. A draft's direct link is still public.

Choose a title carefully. Renaming a page's address is restricted because it can break links and history. Ask an admin if the page belongs in a new section or needs to move.

## Contribute through Discord

Sign in on the website once so the bot can find your account and permissions. In a server channel the bot can read, mention **Retro Porting Toolkit Agent** first, then give a focused request with source facts.

For an existing page:

```text
@Retro Porting Toolkit Agent wiki edit /docs/start/quickstart
Clarify the setup step using these facts: ...
```

For a new page:

```text
@Retro Porting Toolkit Agent wiki new start Setup guide
Write a guide using these facts: ...
```

Use an actual bot mention selected in Discord. Replace the example facts with the instructions and sources you want included. The bot uses the same docs permissions as the editor and checks access again before saving.

## History and moderation

Choose **History** on a docs page to see its revisions. Select a revision to inspect its changes or preview the earlier page. You can compare it with the current version.

Admins can restore a revision with a reason. Restoration creates a new commit and restores the page's saved local media together with its text. Earlier history remains available.

An admin may protect a page from community edits or disable an account's contributions. Disabling blocks both the website and linked bot contributions, including existing signed-in sessions. It keeps the person's earlier work and does not ban them from Discord. Ask an admin if you think access was removed by mistake.
