Online-supported recomp of bomberman online for the dreamcast

## Project

A native C/C++ recompilation of Bomberman Online \(Sega Dreamcast, USA, MK-51065 V1.004\), built on dreamcomp-style static SH-4 recompilation.

The original game is © SEGA / HUDSON SOFT. This repository contains no game data. You must supply your own disc image. Original online multiplayer compatibility is a core requirement, not an optional extra.

Milestone 1 is in progress. See docs/PLAN.md for the current verified checkpoint and the exact blockers. Do not read a row in this table as more than it says.
