Super Metroid has an early [SNESRecomp](/hardware/super-nintendo) build.

This page should be read as a progress marker, not a finished port.

## Playable status

Partial. The build boots, renders, plays audio, completes the attract demo, starts a new game, traverses doors, pauses, and saves at Samus's ship.

Past that, it is still a work in progress and needs broader testing.

Windows and Linux packages are on the GitHub releases page. It is built from a dump you provide: you hand your own Super Metroid ROM to the executable.
