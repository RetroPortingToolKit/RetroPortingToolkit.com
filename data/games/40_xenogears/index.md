XenogearsRecomp is an independent community project by OpokXeno.

It rebuilds Xenogears Disc 1 as a native PC application using [PSXRecomp](/hardware/playstation). The interesting part is how it handles code the game loads later from disc.

## Playable status

Alpha. Prebuilt releases for Windows, macOS, and Linux are published on GitHub. You point the launcher at a disc dump you provide. No BIOS file is needed by default because an open-source BIOS is bundled.

The game boots, plays through the title screen, intro FMV, and opening gameplay with rendering, audio, input, and memory-card saves working. A full playthrough has not been validated, so anything past the opening should be treated as unverified.

## What the recomp adds

The launcher exposes renderer choice, widescreen, screen-look options, and controller settings. The project still treats most enhancements as unpolished.
