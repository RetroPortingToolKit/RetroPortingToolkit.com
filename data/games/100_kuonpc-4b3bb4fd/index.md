Started and currently running at a Kuon Decomp. currently in the early phases but making good progress

## Project

A matching decompilation of Kuon \(FromSoftware, 2004, PlayStation 2\), targeting the PAL release SLES-53411 v1.01. The long-term goal is a native PC port.

This repo contains no game code or data. You need your own disc.

See SPEC.md for the project plan and CLAUDE.md for the matching rules and agent workflow.
