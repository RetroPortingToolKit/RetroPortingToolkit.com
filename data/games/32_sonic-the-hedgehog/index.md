Sonic the Hedgehog was the first game brought up on [SegaGenesisRecomp](/hardware/sega-genesis).

It proved the basic path for the Genesis ecosystem: native PC code, a launcher, and enough framework coverage to run a real Genesis game.

![Green Hill Zone, running as a native build.](/previews/sonic-the-hedgehog.mp4)

## Playable status

Playable alpha. The game is believed playable end to end, but has not been fully tested. Expect some visual and audio bugs.

Windows builds are on the releases page, alongside experimental Linux and macOS builds. The game is built from a ROM dump you provide.

## What the recomp adds

Experimental 16:9 widescreen. The renderer draws extra columns on each side instead of stretching the original picture.

The launcher also offers intro skip, window scaling, volume control, and controller setup.
