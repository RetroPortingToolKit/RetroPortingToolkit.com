MegaManX-X is a community project by Team Resurgent, described as a "Port of MegaManX to Original Xbox Using RXDK / XDK". It takes the [Mega Man X](/games/mega-man-x) SNES recompilation, a fully playable native build produced by snesrecomp, and points it at original Xbox hardware.

## Can I play it?

Source is public, but no release build is available. The project is in development with no releases yet.

## Requirements

The port builds on the Mega Man X recomp, which requires your own legally dumped ROM.

## Technical notes

Because the game exists as portable code compiled for modern systems rather than an emulated ROM, it can be retargeted at console homebrew toolchains.
