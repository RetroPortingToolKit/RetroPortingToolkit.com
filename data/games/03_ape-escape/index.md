Ape Escape is one of the most popular games in the [PSXRecomp](/hardware/playstation) lineup, and one of the youngest. The current release is v0.1.2 (2026-08-05), which added an experimental Linux AppImage alongside the existing builds.

## What works today

The game runs through the recompiled runtime. This is an early alpha, so expect the project to be rougher than the interest around it might suggest.

## Enhancements

Experimental opt-in widescreen in 16:9, 21:9, and Adaptive modes, FMV skipping, and temporal frame blending with a display-refresh picker so blending matches your monitor.

No game data is distributed; the project builds from your own legally dumped disc image.
