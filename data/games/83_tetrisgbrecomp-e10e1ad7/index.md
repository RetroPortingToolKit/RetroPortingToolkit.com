Tetris recompiled for the Game Boy using a fork of gb-recompiled · Part of the R.A.I.D. community

## Project

Static recompilation of Tetris \(Game Boy\) for native PC. Built with the gb-recompiled engine and the shared recomp-ui launcher.

- All game modes \(A-Type, B-Type\)
- Title screen, menus, demo/attract mode
- Music and sound effects
- recomp-ui launcher: ROM picker with CRC gate, settings/video/input overlay \(F1\)
