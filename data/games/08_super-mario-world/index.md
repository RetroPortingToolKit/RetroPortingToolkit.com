Super Mario World was the first game [SNESRecomp](/hardware/super-nintendo) ever recompiled, and it is still the flagship. Built on the SMWDisX disassembly, 1,937 of the game's 2,074 functions carry real names in the recompiled source, which makes it the leading example of a disassembly-annotated recomp. The current release is v0.11.0 (2026-08-12).

## What works today

The recompilation is believed playable end to end, per the SNESRecomp README. A co-op build also exists.

## Enhancements

Three widescreen modes: Standard 4:3, Fixed 16:9, and Adaptive. MSU-1 support brings CD-quality audio. v0.11.0 added an experimental Smash Bros 64 mod catalog, with Captain Falcon as the first character option; it is off by default and requires your own ROMs for the donor content.

No game data is distributed; the project builds from your own legally dumped ROM.
