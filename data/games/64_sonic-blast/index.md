Sonic Blast is a very early [Master System / Game Gear](/hardware/master-system-game-gear) tech demo.

It proves the framework can handle a Game Gear title, but it is not a full port.

## Playable status

Tech demo. An early Windows build is on the releases page. There is no launcher: you run it from a command line and hand it the path to a ROM dump you provide.

The checked path is narrow. It boots through the intro to the title screen, and gameplay beyond that is largely unexercised. Expect bugs.
