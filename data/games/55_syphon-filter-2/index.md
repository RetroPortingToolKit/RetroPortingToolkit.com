Syphon Filter 2 Recompiled is a community project by Alexbeav.

It rebuilds the complete two-disc PlayStation release as a native Windows program through [PSXRecomp](/hardware/playstation). The important claim is coverage: both discs and the transition between them have been checked.

## Playable status

Playable alpha on Windows. The build happens on your machine from disc images you provide.

Put your own Disc 1 cue and bin beside the extracted kit, with Disc 2 alongside if you have it, and run the setup script. Later sessions use the play script it generates.

An open-source BIOS is bundled. The project is direct about the label: this is an alpha, not a finished PC port.

Three opt-in features stand out: native 16:9, PGXP geometry correction, and mouse look for camera and manual aim.

It does not add a higher frame rate. High-refresh experiments were tried and removed because they caused serious rendering problems.
