TwistedMetal4 Recompiled is an independent community project built on [PSXRecomp](/hardware/playstation), covered by the Japanese-language site retro-gamer.jp (2026-08-15).

## Can I play it?

Per the coverage, the project targets Windows, macOS, and Linux and preserves the original 4-player multitap multiplayer. The project's repository URL has not yet been confirmed by this site, so the press coverage is linked instead of a download.

## Known issues

Rollback netcode is planned but disabled in the current release.

## Technical notes

The pipeline is the toolkit's standard one: MIPS R3000A machine code becomes C, and the C compiles to native x86-64.
