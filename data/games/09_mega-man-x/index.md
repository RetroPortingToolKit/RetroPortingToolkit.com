Mega Man X is [SNESRecomp](/hardware/super-nintendo)'s most mature title, a core project maintained alongside the framework itself.

## Can I play it?

Playable start to finish. Fully playable per the framework README, completable start to finish per the release announcement, and shipped as a released native build, currently v1.4.3 (2026-08-16). You build from your own ROM dump.

## Enhancements

Experimental true widescreen renders a wider field of view rather than stretching: 16:9 from the 4:3 presentation, or 32:21 from the raw 8:7 framebuffer. An MSU-1 audio mod adds CD-quality music.

## Requirements

Your own legally dumped ROM.

## Technical notes

This was the first game recompiled without an explicit disassembly as reference, a milestone for the toolchain. A community port of this recompilation to original Xbox hardware exists as [Mega Man X for Xbox](/games/mega-man-x-xbox).
