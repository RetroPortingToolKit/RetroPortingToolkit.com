A core project: Metroid is one of the ten commercial titles supported by [NESRecomp](/hardware/nes). It made the list partly because it has a good public disassembly, which the framework prioritizes: symbol names make the recompiled output easier to verify and work on.

## Can I play it?

Builds from your own ROM dump through the shared NESRecomp runner, with save-state slots. Windows is the primary host platform; macOS support is experimental.
