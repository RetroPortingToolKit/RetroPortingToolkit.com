Mega Man X2 is a SNESRecomp project.

It matters because the game uses Capcom's Cx4 chip. That makes it useful framework work, even while the enhancement layer is still being checked.

## Can I play it?

Yes, for the stock game. Mega Man X2 can be played from start to finish without enhancements.

Enhancements are a separate question. Widescreen and other changes still need their own verification.

## What this port adds

- A native SNESRecomp path for Mega Man X2.
- Widescreen work as an opt-in mod.
- Cx4 support without asking the player for a separate firmware file.

Treat the stock game and the enhancement work separately when judging the project.
