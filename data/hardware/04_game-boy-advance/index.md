GBARecomp is an alpha ecosystem.

It turns Game Boy Advance games into native apps. It already has useful public previews, but it still needs refinement and testing.

You provide your own cartridge dump. Most GBA projects also ask for a legally obtained GBA BIOS unless that project says otherwise.

## What runs today

Public work includes [The Minish Cap](/games/minish-cap), [Mega Man Zero](/games/mega-man-zero), [WarioWare Twisted!](/games/warioware-twisted), [Mario Kart Super Circuit](/games/mario-kart-super-circuit), [Boktai](/games/boktai), paired Pokemon projects, [Dragon Ball Z: Buu's Fury](/games/dbz-buus-fury), and other active previews.

Some are playable. Some are there to prove a hardware feature, Android support, a renderer path, or a specific enhancement.

The exact state still belongs on each game page. The platform page is here to explain the ecosystem.

## What GBA ports can add

- Adaptive widescreen that opens the view instead of stretching the 240x160 image.
- Save states and modern display options.
- Mods as toggleable packages.
- Real-time clock sync for games that used a cartridge clock.
- Android experiments, including phone gyro input for WarioWare Twisted!.
- Modern replacements for cartridge hardware, such as Boktai's solar sensor using local weather.
- Game-specific enhancements, such as higher frame rate work in Mario Kart Super Circuit.

## What to expect

GBARecomp can run games with meaningful enhancements today, but it is not a finished whole-console solution.

Each game can still have its own problems: cartridge hardware, timing, save types, sensors, BIOS behavior, optimization, or game-specific bugs. A playable preview means that project has done enough work for that game to be useful.
