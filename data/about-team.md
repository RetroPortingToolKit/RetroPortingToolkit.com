Retro Porting Toolkit is a collaborative initiative around native ports of classic games.

The team works across static recompilation, runtime accuracy, debugging tools, release packaging, netplay, and public documentation. The project is still evolving, and so is this page.

> **Note.** This is a boilerplate team page. Each team member should replace their placeholder with their own description before the page is linked publicly.

## How to read this site

Retro Porting Toolkit is collaborative. Not every project mentioned here is owned, maintained, or supported by the same person.

Platform and project pages should be read as status notes for the work they describe. The linked project repository remains the authority for its own license, release policy, issue tracker, and support expectations.

The goal of this page is simple: credit the people doing the work, avoid blurring ownership, and give the team a place to describe their roles in their own words.
