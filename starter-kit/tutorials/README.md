# Tutorials

Full walkthroughs live on the site rather than in this repository, so they can
carry screenshots and be corrected without a release.

Read them at <https://retroportingtoolkit.com/blog>.

## Which one you want

**[Recompile a PlayStation game you own, start to finish](https://retroportingtoolkit.com/blog/tutorial-recompile-a-playstation-game)**
You are at a terminal and you want to do it yourself. Prerequisites, the scaffold
command, generate, build, run, and what to check at each step. Start here if your
game is a PlayStation title.

**[Let your agent do the recompilation](https://retroportingtoolkit.com/blog/tutorial-let-your-agent-do-the-recomp)**
The same job, handed to an AI coding agent. Includes the prompt to paste, the non
interactive form of the scaffold that an agent needs, and the points where the
agent has to stop and ask you to look at the screen.

## The order to read them in

If you want to work through the port yourself, start with the PlayStation
tutorial. If an agent is doing the work, use the agent tutorial instead.
