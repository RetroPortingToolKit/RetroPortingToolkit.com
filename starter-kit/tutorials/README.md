# Tutorials

Full walkthroughs live on the site rather than in this repository, so they can
carry screenshots and be corrected without a release.

Read them at <https://retroportingtoolkit.com/blog>.

## Which one you want

**[Recompile a PlayStation game you own, start to finish](https://retroportingtoolkit.com/blog/tutorial-recompile-a-playstation-game)**
You are at a terminal and you want to do it yourself. Prerequisites, the scaffold
command, generate, build, run, and what to check at each step. Start here if your
game is a PlayStation title.

**[Let your agent do the recompilation](https://retroportingtoolkit.com/blog/tutorial-let-your-agent-do-the-recomp)**
The same job, handed to an AI coding agent. Includes the prompt to paste, the non
interactive form of the scaffold that an agent needs, and the points where the
agent has to stop and ask you to look at the screen.

**[Start a NES port by copying a working one](https://retroportingtoolkit.com/blog/tutorial-start-a-nes-port)**
There is no scaffold on NES, so you reproduce a working port's structure. What to
copy, what to replace, and what the per game configuration has to say.

**[Start a Game Boy Advance port](https://retroportingtoolkit.com/blog/tutorial-start-a-game-boy-advance-port)**
The same, for Game Boy Advance, which has more moving parts: configuration,
symbols and per region files. Also covers why the exact original cartridge dump
matters and what happens when it is not exact.

**[It boots, then it crashes](https://retroportingtoolkit.com/blog/tutorial-it-boots-then-crashes)**
The most useful of the five, and the one about the actual work. Your port built
and then died twenty minutes in. Why that happens, what a dispatch miss is, and
how to turn a crash into a fix.

## The order to read them in

If you have a PlayStation game: tutorial one, then five.
If you have anything else: three or four, then five.
If an agent is doing the work: two, then five.

Tutorial five applies to every console and is where most of your time goes.
